# めばえ ― ADHD向け集中学習アプリ

一般的な勉強用タイマーに、ADHD特性（時間の見積もりが難しい／タスク着手のハードルが高い／
気が散りやすい／達成感が積み上がりにくい）に配慮した工夫を足したシンプルな学習アプリです。
ビルド不要の HTML / CSS / JavaScript のみで作っているので、VSCode でそのまま開いて
編集・実行できます。

## 使い方（VSCode）

1. このフォルダを VSCode で開く（`code .` または「フォルダを開く」）
2. 拡張機能 **Live Server**（Microsoft/Ritwick Dey製）をインストール
3. `index.html` を右クリック →「Open with Live Server」
4. ブラウザが開いて動作します

Live Server を入れたくない場合は、`index.html` をブラウザにドラッグ＆ドロップするだけでも
動きます（Web Audio API を使う通知音以外は問題なく動作します）。

## ファイル構成

```
mebae-app/
├── index.html   … 画面構造
├── style.css    … デザイン（配色トークンは style.css 冒頭の :root に集約）
├── script.js    … タイマー・タスク・保存ロジック
└── README.md
```

すべて `localStorage` に保存されるため、サーバーやアカウント登録は不要です。
（保存はブラウザ単位なので、別ブラウザ／シークレットモードでは共有されません）

## 追加した機能

- **ログイン（名前＋4桁の合言葉）**
  サーバーを持たないアプリなので、これは「同じ端末を複数人で使うときにデータを分ける」
  ための簡易的な仕組みです。初めての名前は自動で新規登録され、次回からは同じ名前と
  合言葉でログインすると続きが見られます。パスワード再発行などはできないため、
  他のサービスと同じ合言葉は使わないでください。

- **達成済みタスク一覧**
  「今日のタスク」パネルが「進行中」と「✓ 達成済み」に分かれ、完了したタスクは
  チェック済みの状態で下に表示されます。間違えてチェックした場合はもう一度押すと
  進行中に戻せます。

- **カレンダー**
  月表示のカレンダーに予定（日付・開始時刻／終了時刻（任意）・タイトル・カテゴリ）を追加できます。
  カテゴリは「勉強／課題／テスト／その他」の4種類で、色分けされたドットとしてカレンダー上に
  表示されるので、月全体で予定が多い日・少ない日をひと目で把握できます。
  「その他」を選ぶとカテゴリ名の自由入力と色の指定ができます（例：資格試験を赤で目立たせるなど）。
  画面は左側にカレンダー本体＋選択日の予定一覧、右側に入力フォームを配置しています。
  日付をクリックするとその日の予定一覧が左下に表示され、削除もその場でできます。「今日」ボタンで現在の月にすぐ戻れます。

- **今日の記録（勉強メモ）**
  日付・勉強時間（〇時間〇分）・タスク（今日入力したタスクから選択）・100文字以内の
  ひとことメモを記録できます。記録は新しい順にリスト表示され、削除も可能です。

## ADHD向けに入れた工夫

- **視覚的なタイマー（時間の見積もり対策）**
  リング状のプログレスバーで「残りがどれくらいか」を直感的に把握できるようにしています。
  数字だけだと時間感覚がつかみにくい「タイムブラインドネス」対策です。

- **とりあえず2分だけボタン（着手のハードル対策）**
  「25分やる」は腰が重くても「2分だけ」なら始めやすい、という着手のハードルを下げる
  仕組みです。2分終わった時点で続けるかどうかを自分で選べます。

- **タスクの自動分解（あいまいなタスク対策）**
  「レポートを書く」のような大きく曖昧なタスクを入力すると、
  「机に用意する」→「最初の一歩だけ」→「続きを進める」→「見直す」という
  具体的で小さいステップに自動で分解します。何から手をつければいいか迷う時間を減らします。

- **気になったことメモ（脱線対策）**
  集中中にふと浮かんだ用事や考えごとを、その場で対応せずに一旦「置いておく」場所です。
  気になることを頭の外に出すことで、今のタスクに意識を戻しやすくします。

- **集中の庭（達成感の可視化）**
  セッションを1つ終えるごとに、庭に小さな芽や花が増えていきます。
  ポイントや数字よりも「見て嬉しい」変化の方がADHD特性的にはご褒美として機能しやすいため、
  視覚的な成長表現にしています。

- **やさしい休憩リマインダー（過集中対策）**
  設定した回数だけ集中セッションを終えると、責めるトーンではなく
  「ちょっと一息つこうか」と声をかける形で休憩を促します（強制はしません）。

- **ながら作業モード／アニメーション減量設定**
  背景の淡いアニメーションは刺激になりすぎる人もいるため、設定からON/OFFできます。

## カスタマイズしたい時

- 配色を変えたい → `style.css` 冒頭の `:root { --bg: ...; --spark: ...; }` を編集
- タスク分解のテンプレートを変えたい → `script.js` の `addBreakdown()` 関数
- 庭に出てくる絵文字を変えたい → `script.js` の `GARDEN_EMOJI` 配列
- タイマーの長さプリセットを増やしたい → `index.html` の `#lengthPresets` 内の `<button class="chip">`
